# UX Portfolio

Hanna Jansson's UX design portfolio — a focused subset of case studies from the
main [portfolio](https://github.com/hannajansson/portfolio) repo, tailored to
UX and interaction design work only.

Built with React 19, TypeScript, and Vite. See [CLAUDE.md](./CLAUDE.md) for
architecture notes.

## Commands

```bash
npm run dev       # Start dev server (Vite)
npm run build     # Type-check + production build
npm run lint      # ESLint
npm run preview   # Preview production build
```
